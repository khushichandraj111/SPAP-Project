# Student Placement Analytics & Prediction System (SPAP)

A web-based application designed to manage student placement workflows and predict placement outcomes using Machine Learning.

## Tech Stack & Features
- Frontend & UI: HTML5, CSS3, JavaScript
- Backend & ML: Python, Flask framework, Machine Learning models
- Structure: Organized in CSS, HTMLs, and ML folders

## How to Run Locally
1. Clone the repository using git clone command
2. Run the application using: python application.py
